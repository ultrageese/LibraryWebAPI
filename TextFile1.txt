Создать контроллеры со следующими методами по схеме:
PS! У нас пока нет авторизации, так что все методы открытые
Контроллеров много, так что надо упростить тестирование, ставим swagger:
1. Ставим nuget Swashbuckle.AspNetCore
2. Редактируем файл Program:
До строки builder.Build():
	builder.Services.AddEndpointsApiExplorer();
	builder.Services.AddSwaggerGen();
	
Там где строка if (app.Environment.IsDevelopment()), меняем ее тело следующим образом
if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI();
}
3. Открываем файл launchSettings.json:
	ставим настройку "launchBrowser": true, и добавляем "launchUrl": "swagger",

GET    /api/readers/{id}         // Данные конкретного читателя
POST   /api/readers              // Создание нового читателя
PUT    /api/readers/{id}         // Обновление данных читателя

GET    /api/readers/{id}/cards   // Читательские билеты читателя
